# Cable External Rotation

Exercise ID: EX037
Category: Shoulders
Equipment: Light cable or band
Primary muscles: Rotator cuff

## Step-by-step technique
1. Setup: Keep elbow near side bent 90 degrees.
2. Movement: Rotate forearm outward without moving upper arm.
3. Return: Return slowly.
4. Repeat with controlled tempo and comfortable range of motion.

## Common mistakes
Using torso rotation; too much weight.

## Beginner modification / alternative
Band external rotation. Start with light resistance and practice form before adding load.

## Safety guidance
Warm up first. Stop if you experience sharp pain, dizziness, or unusual symptoms. Use a qualified trainer for hands-on form feedback. This guide is general education, not medical advice.
