# Face Pull

Exercise ID: EX031
Category: Back
Equipment: Cable station with rope
Primary muscles: Rear deltoids, upper back

## Step-by-step technique
1. Setup: Set rope at face height, stand stable.
2. Movement: Pull rope toward forehead, separating hands.
3. Return: Extend arms slowly.
4. Repeat with controlled tempo and comfortable range of motion.

## Common mistakes
Arching back; shrugging.

## Beginner modification / alternative
Band pull-apart. Start with light resistance and practice form before adding load.

## Safety guidance
Warm up first. Stop if you experience sharp pain, dizziness, or unusual symptoms. Use a qualified trainer for hands-on form feedback. This guide is general education, not medical advice.
