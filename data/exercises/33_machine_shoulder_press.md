# Machine Shoulder Press

Exercise ID: EX033
Category: Shoulders
Equipment: Shoulder press machine
Primary muscles: Deltoids, triceps

## Step-by-step technique
1. Setup: Adjust seat so handles begin near shoulders.
2. Movement: Press handles upward without locking forcefully.
3. Return: Return slowly.
4. Repeat with controlled tempo and comfortable range of motion.

## Common mistakes
Seat misalignment; excessive back arch.

## Beginner modification / alternative
Dumbbell shoulder press. Start with light resistance and practice form before adding load.

## Safety guidance
Warm up first. Stop if you experience sharp pain, dizziness, or unusual symptoms. Use a qualified trainer for hands-on form feedback. This guide is general education, not medical advice.
