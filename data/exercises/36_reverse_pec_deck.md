# Reverse Pec Deck

Exercise ID: EX036
Category: Shoulders
Equipment: Reverse fly machine
Primary muscles: Rear deltoids

## Step-by-step technique
1. Setup: Sit facing machine with chest supported.
2. Movement: Open arms outward/back with soft elbows.
3. Return: Return slowly.
4. Repeat with controlled tempo and comfortable range of motion.

## Common mistakes
Shrugging; neck jutting.

## Beginner modification / alternative
Bent-over reverse fly. Start with light resistance and practice form before adding load.

## Safety guidance
Warm up first. Stop if you experience sharp pain, dizziness, or unusual symptoms. Use a qualified trainer for hands-on form feedback. This guide is general education, not medical advice.
